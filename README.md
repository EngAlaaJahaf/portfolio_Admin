# Portfolio - نظام بورتفوليو متكامل

نظام بورتفوليو احترافي للمطورين مع لوحة تحكم شاملة لإدارة المحتوى.

## المميزات

### لوحة التحكم (Admin Panel)
- **إدارة كاملة للبيانات**: إضافة، تعديل، وحذف لجميع الأقسام
- **رفع الصور**: إمكانية رفع صور المشاريع والملف الشخصي
- **نظام الرسائل**: استقبال رسائل التواصل والرد عليها
- **إدارة الفئات**: إضافة فئات وتصنيفات جديدة للمشاريع
- **إدارة التقنيات**: إضافة وتعديل التقنيات المستخدمة
- **إعدادات الموقع**: تخصيص عنوان الموقع والوصف وكلمات مفتاحية

### الأقسام
- الصفحة الرئيسية مع Hero Section
- قسم نبذة عني
- قسم المهارات التقنية
- قسم المشاريع
- قسم الاهتمامات الأمنية
- قسم التعليم والشهادات
- قسم التواصل

## متطلبات التشغيل

- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث
- Apache/Nginx Web Server
- امتداد PDO مفعل في PHP

## التثبيت

### 1. استيراد قاعدة البيانات
```sql
CREATE DATABASE portfolio_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE portfolio_db;
-- ثم استورد ملف database.sql
```

### 2. تعديل إعدادات الاتصال
انسخ `config/config.example.php` إلى `config/config.php` وعدّل الإعدادات:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'portfolio_db');
define('DB_USER', 'root');
define('DB_PASS', 'your_password');
```

### 3. بيانات الدخول الافتراضية
- **اسم المستخدم**: admin
- **كلمة المرور**: admin123

### 4. إعداد مجلد الرفع
تأكد من وجود مجلد `uploads/` مع صلاحيات الكتابة:
```bash
chmod 755 uploads/
chmod 755 uploads/projects/
```

## لوحة التحكم

### الوصول للوحة التحكم
افتح `admin/index.php` في المتصفح

### الميزات المتوفرة:

#### 1. المعلومات الشخصية
- تعديل الاسم والمسمى الوظيفي
- رفع صورة الملف الشخصي
- تحديث معلومات التواصل
- التحكم في حالة التوفر

#### 2. المشاريع
- إضافة مشاريع جديدة مع صور
- تعديل المشاريع الحالية
- حذف المشاريع
- تحديد المشاريع المميزة
- إضافة التقنيات المستخدمة

#### 3. المهارات
- إضافة مهارات جديدة
- إضافة وسوم للمهارات
- إضافة مؤشرات تقدم
- ترتيب العرض

#### 4. التعليم
- إضافة شهادات ودرجات
- إضافة إنجازات
- ترتيب العرض

#### 5. الأمن السيبراني
- إضافة اهتمامات أمنية
- تخصيص الألوان والأيقونات

#### 6. التقنيات
- إضافة تقنيات جديدة
- تخصيص الألوان

#### 7. الفئات
- إضافة فئات للمشاريع
- إنشاء slugs للتواصل مع API
- تفعيل/إلغاء الفئة

#### 8. الرسائل
- عرض جميع الرسائل
- النقر على رسالة لعرض التفاصيل
- الرد على الرسائل
- تحديد كمقروءة
- حذف الرسائل

#### 9. الإعدادات
- عنوان الموقع
- وصف الموقع
- الكلمات المفتاحية
- إعدادات الفوتر

## قاعدة البيانات

### الجداول الرئيسية:

- `personal_info` - المعلومات الشخصية
- `technologies` - التقنيات المعروضة
- `skills` - المهارات
- `skill_tags` - وسوم المهارات
- `skill_progress` - مؤشرات التقدم
- `projects` - المشاريع
- `project_technologies` - تقنيات المشاريع
- `categories` - فئات المشاريع
- `cybersecurity_interests` - الاهتمامات الأمنية
- `education` - التعليم والشهادات
- `education_achievements` - إنجازات التعليم
- `contact_messages` - رسائل التواصل
- `settings` - إعدادات الموقع
- `media` - الوسائط المرفوعة
- `custom_data` - بيانات مخصصة

## الأمان

- جميع المدخلات يتم تنظيفها باستخدام `htmlspecialchars()`
- استخدام Prepared Statements لتجنب SQL Injection
- التحقق من تسجيل الدخول للأدوار الحساسة

## تخصيص الألوان

عدّل المتغيرات في ملف `header.php`:

```css
:root {
    --primary-dark: #0a0e17;
    --primary-blue: #00d4ff;
    --primary-green: #00ff88;
}
```

## نصائح للأمان

1. **غيّر كلمة مرور لوحة التحكم** بعد أول تسجيل دخول
2. **فعّل HTTPS** على خادمك
3. **حدّث PHP و MySQL** للإصدارات الأخيرة
4. **استخدم كلمات مرور قوية** لقاعدة البيانات

## استكشاف الأخطاء

### خطأ في الاتصال بقاعدة البيانات:

- تأكد من صحة إعدادات `config/config.php`
- تأكد من تشغيل خدمة MySQL
- تحقق من صلاحيات المستخدم

### الصور لا تظهر:

- تأكد من وجود مجلد `uploads/`
- تأكد من صحة مسار الصورة
- تحقق من صلاحيات الملفات

### خطأ في العرض:

- تأكد من تفعيل `mod_rewrite` إذا كنت تستخدم Apache
- تحقق من إعدادات PHP memory_limit
